# Text Cleaner

**Subject:** Text and Speech Analysis

Remove extra spaces and normalize text.

## Run
Open `index.html` in a modern browser.

## GitLab
Create a GitLab project, upload `index.html`, `style.css`, `script.js`, and this README, then commit the files. Uploading files does not automatically publish a live website; GitLab Pages may need separate setup.

## Notes
This is a beginner-friendly educational mini project. Speech features may vary by browser/device.
